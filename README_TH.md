# Horizon Nav ภาษาไทย — รุ่นทดสอบ

เวอร์ชันแยกจาก Horizon Nav ต้นฉบับ โดยอิงซอร์สรุ่น 1.0.361

- แปลเมนู การตั้งค่า ขั้นตอนเริ่มต้น และหน้าจอ Android Auto
- คำแนะนำเลี้ยว วงเวียน ช่องทาง ระยะทาง และคำเตือนเป็นภาษาไทย
- ขอผลค้นหาและเส้นทางจาก TomTom และ Mapbox เป็นภาษาไทย
- แผนที่ Mapbox ขอชื่อภาษาไทยเมื่อผู้ให้บริการมีข้อมูล
- รองรับคำสั่ง เช่น “กลับบ้าน”, “หยุดนำทาง”, “หาปั๊มน้ำมัน”, “นำทางไปวัดพระแก้ว”
- ชื่อแพ็กเกจ `com.headunit.nav.thai` ติดตั้งคู่กับต้นฉบับได้ ข้อมูลเดิมไม่ถูกย้ายอัตโนมัติ
- ไม่ฝังคีย์ Mapbox หรือ TomTom ใส่คีย์ของคุณใน การตั้งค่า > คีย์และบัญชี

## ดาวน์โหลดและติดตั้ง

เมื่อ Actions ผ่าน จะมี `HorizonNav-Thai.apk` ใน Releases แท็ก `app`
เปิด APK บน Android 8 ขึ้นไป แล้วอนุญาตติดตั้งจากแหล่งนั้น
หากใช้ Android Auto ให้เปิดตัวเลือกนักพัฒนา > แหล่งที่ไม่รู้จัก และเลือกแอปในตัวปรับแต่ง Launcher
บางเครื่องต้องติดตั้งผ่าน AAEnabler หรือ KingInstaller เช่นเดียวกับต้นฉบับ

ติดตั้งเสียงภาษาไทยในระบบอ่านออกเสียงของ Android ก่อนใช้เสียงนำทาง
หากเสียงไทยยังไม่พร้อม แอปจะแสดงคำแนะนำและไม่ส่งภาษาไทยไปยังเสียงอังกฤษ
นี่ใช้ Android TTS ไม่ได้เพิ่ม Gemini TTS

## ขอบเขตของคำแปล

คงชื่อสถานที่ ชื่อถนน และข้อความจากผู้ให้บริการไว้ตามข้อมูลจริง
ประเทศที่ไม่ได้มีคำแปลในรายการ แพ็กแผนที่บางแห่ง บันทึกวินิจฉัย และหมายเหตุอัปเดตเดิมอาจเป็นอังกฤษ
ไม่ได้แปลงเพนนีเป็นบาทหรืออัตราสิ้นเปลืองโดยเปลี่ยนเพียงป้ายชื่อ เพราะจะทำให้ตัวเลขผิดความหมาย
ข้อความนำทางออฟไลน์สร้างจากรหัส maneuver ในเครื่อง ไม่ต้องพึ่งชุดเสียงไทยของ Valhalla
ควรทดลองเส้นทางและตรวจการจัดวางบนมือถือและจอรถจริงก่อนใช้งานประจำ

## การ Build และการลงนาม

Workflow ใหม่ Build จากไฟล์ `app/` โดยตรง ไม่แตก `HorizonNav.zip` เก่ามาทับคำแปล
รัน JVM tests ก่อนสร้าง APK และตรวจลายเซ็นก่อนอัปโหลด
Fork ใหม่อาจต้องกดเปิดใช้งาน Actions ครั้งแรกด้วยตนเอง
หาก Maven ของ Mapbox ต้องการสิทธิ์ดาวน์โหลด ให้ตั้ง secret `MAPBOX_DOWNLOADS_TOKEN` ที่มีสิทธิ์ Downloads:Read

รุ่นทดสอบใช้คีย์ของ Fork แยกจากต้นฉบับ เก็บใน Actions cache เพื่อใช้ต่อระหว่าง Build
cache อาจถูกล้างหรือหมดอายุ ซึ่งจะทำให้ APK ถัดไปลงทับรุ่นก่อนหน้าไม่ได้
ควรตั้งคีย์ release ส่วนตัวแบบถาวรก่อนแจกจ่ายจริง อย่าลบแอปเพื่อเปลี่ยนลายเซ็นก่อนสำรองข้อมูล

แก้คำแปลคงที่ใน `localization/th.tsv` แล้วรัน `python3 tools/generate_thai_catalog.py`
`th-templates.tsv` เป็นรายการคำแปลที่ใช้ปรับข้อความประกอบตัวแปรในซอร์ส
API key, preference key, maneuver ID, URLs และข้อมูลผู้ใช้ไม่ถูกแปล
